# Manual do Usuário — Impacto Social (versão demonstrativa)

> Todo o conteúdo é fictício e nenhum dado que você digitar é enviado ou guardado.

## Navegar
Use o menu no topo: **Início**, **Projetos** e **Cadastro**. No celular, toque em **Menu** (feche com **Fechar** ou a tecla Esc). Usuários de teclado podem pressionar Tab e escolher "Pular para o conteúdo principal".

## Encontrar projetos
1. Abra **Projetos**.
2. Digite um termo (ex.: "horta") e/ou escolha uma categoria.
3. Clique em **Detalhes do projeto** para ver objetivo e localização.
4. Se nada aparecer, use **Limpar filtros**.

## Fazer o cadastro
1. Abra **Cadastro** e preencha os campos marcados com **\***. Complemento é opcional.
2. CPF, telefone e CEP são formatados automaticamente; digite apenas os números.
3. Escolha o tipo (voluntário, doador ou apoiador) e aceite a política de privacidade.
4. Clique em **Validar cadastro**.
   - Se houver erros, uma lista no topo do formulário mostra o que corrigir; clique em um item para ir ao campo.
   - Se estiver tudo certo, aparece a confirmação de que os dados foram validados. **Nenhum cadastro é realmente concluído** nesta versão.
5. **Limpar** apaga o formulário.

## Dúvidas comuns
- **Meu cadastro foi salvo?** Não. Não existe servidor nesta versão.
- **Que CPF usar para testar?** Um número fictício com dígitos verificadores válidos; não use o seu.
